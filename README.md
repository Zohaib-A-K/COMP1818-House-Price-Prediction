# House Price Prediction Using XGBoost
## About the Project

For my COMP1818 coursework, I looked at how machine learning can be used to predict house prices using the Ames Housing dataset.
I compared XGBoost with Linear Regression and a simple Dummy Regressor to see how their predictions differed. I also experimented with different tree depths and regularisation settings to see how they affected the model's performance.
As an additional experiment, I tested whether increasing regularisation when less training data is available would help improve the predictions.

## Dataset
I used the Ames Housing dataset, which contains information about 2,930 houses.
I split the data into three parts:
- 70% for training
- 15% for validation
- 15% for testing
I also handled missing values and converted categorical features into a format the models could use.

## How to Run the Code
I tested the code using Python 3.12.3.
To run it:
1. Download the project files.
2. Make sure `AmesHousing.csv` is in the same folder as `house_price_prediction.py`.
3. Open the project folder in VS Code or another Python environment.
4. Open the terminal and install the required libraries:
   `python -m pip install -r requirements.txt`
5. Run the Python file:
   `python house_price_prediction.py`

The code will run the experiments and save the graphs and results in a folder called `results`.

## What I Tested
The main experiments included:
- Comparing Dummy Regression, Linear Regression and XGBoost.
- Testing different XGBoost tree depths.
- Changing the L2 regularisation strength.
- Training the model with different amounts of data.
- Comparing fixed and adaptive regularisation.
- Repeating the regularisation experiment five times using different random seeds.

## Results
XGBoost gave the best results on the test data, achieving a mean absolute error (MAE) of approximately $14,088 and an R² score of 0.934.

The adaptive regularisation experiment was less successful than I expected. Increasing regularisation when using smaller training sets did not consistently improve the model compared with keeping regularisation fixed.

## Project Files
